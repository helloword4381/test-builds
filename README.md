# 一建学习系统

一个基于浏览器的独立学习系统，专为一级建造师考试设计。所有数据保存在浏览器本地，无需服务器。

## 功能模块

- **课程学习**: 章节视频播放、讲义阅读、学习进度标记
- **每日一练**: 支持随堂课练(10题)和每日复习(50题)两种模式
- **学习计划**: 月历视图、每日任务清单、总体进度追踪
- **错题本**: 自动收集错题、查看解析、手动移出
- **重点朗读**: 使用浏览器语音合成朗读当前内容
- **休息计时**: 10分钟休息倒计时提醒
- **资料导入**: 支持章节、题库、讲义的批量导入
- **数据导出**: 可将所有学习数据备份为JSON文件

## 使用方式

1. 直接用浏览器打开 `index.html` 文件
2. 进入"资料导入"页面，按下方格式准备数据并导入
3. 进入"课程学习"页面开始学习
4. 学习流程:
   - 观看视频 → 查看讲义 → 点击"随堂课练"做10道题 → 点击"休息10分钟"
   - 第二天学新课前，进入"每日一练"做50道复习题

## 资料投喂格式

### 1. 章节数据结构 (JSON)

```json
[
  {
    "id": "ch1",
    "title": "第1章 建筑工程技术",
    "order": 1,
    "sections": [
      {
        "id": "s1-1",
        "title": "1.1 建筑构造要求",
        "video": "video/1-1.mp4",
        "keyPoints": "建筑物分类：按用途分为民用建筑、工业建筑、农业建筑...",
        "completed": false
      },
      {
        "id": "s1-2",
        "title": "1.2 建筑结构技术要求",
        "video": "video/1-2.mp4",
        "keyPoints": "结构的功能要求：安全性、适用性、耐久性...",
        "completed": false
      }
    ]
  }
]
```

字段说明：
- `id`: 唯一标识，建议用 ch1, ch2... 和 s1-1, s1-2... 格式
- `title`: 章节/小节标题
- `order`: 章节排序号
- `video`: 视频文件路径（相对路径或完整URL）
- `keyPoints`: 本节要点/背记内容（用于朗读和快速复习）
- `completed`: 是否已完成学习

### 2. 题库数据结构 (JSON)

```json
[
  {
    "id": "q001",
    "type": "single",
    "chapter": "第1章",
    "section": "s1-1",
    "content": "下列建筑中，属于公共建筑的是？",
    "options": [
      "A. 宿舍",
      "B. 宾馆",
      "C. 住宅",
      "D. 公寓"
    ],
    "answer": ["B"],
    "explanation": "公共建筑是供人们进行各类社会活动的建筑物，如宾馆、办公楼等。",
    "source": "2024年真题"
  },
  {
    "id": "q002",
    "type": "multiple",
    "chapter": "第1章",
    "section": "s1-1",
    "content": "结构的可靠性包括哪些？",
    "options": [
      "A. 安全性",
      "B. 适用性",
      "C. 耐久性",
      "D. 经济性"
    ],
    "answer": ["A", "B", "C"],
    "explanation": "结构的可靠性包括安全性、适用性和耐久性，概括为结构的可靠性。",
    "source": "讲义重点"
  }
]
```

字段说明：
- `id`: 唯一标识，建议用 q001, q002... 格式
- `type`: 题型，可选 `single`(单选) / `multiple`(多选) / `truefalse`(判断)
- `chapter`: 所属章节名称（用于分类统计）
- `section`: 所属小节id（用于随堂课练匹配）
- `content`: 题目内容
- `options`: 选项数组，每个选项以 "A."、"B." 等开头
- `answer`: 正确答案数组，如 `["A"]` 或 `["A", "B"]`
- `explanation`: 答案解析
- `source`: 题目来源（可选）

### 3. 讲义导入

讲义不需要JSON格式，直接在"资料导入"页面：
1. 选择章节和小节
2. 将讲义文本粘贴到文本框中
3. 点击"导入讲义"

讲义内容支持纯文本，建议按以下结构整理：

```
【本节重点】
1. xxxxxx
2. xxxxxx

【难点解析】
xxxxxx

【易错点】
xxxxxx
```

## 学习流程设计

### 当天学习流程
1. 进入"课程学习"，选择当前小节
2. 点击"播放视频"观看课程
3. 点击"查看讲义"阅读配套讲义
4. 点击"随堂课练(10题)"做题巩固
5. 点击"休息10分钟"，系统自动倒计时
6. 休息结束后继续下一小节

### 第二天复习流程（学新课之前）
1. 进入"每日一练"
2. 选择"每日复习(50题)"
3. 系统自动出题：
   - 10道预习题（下一节内容）
   - 10道昨日回顾（昨天刚做过的题）
   - 10道错题重做
   - 20道薄弱练习（做题次数最少的题）
4. 提交后查看得分，可选择继续休息

## 数据管理

- 所有数据保存在浏览器的 IndexedDB 中
- 点击"设置"页面的"导出所有数据"可将数据备份为JSON文件
- 点击"清空所有数据"将删除所有本地数据（谨慎操作）
- 更换浏览器或清除浏览数据会导致数据丢失，建议定期导出备份

## 注意事项

1. **视频路径**: 如果视频是本地文件，需要将视频文件放在项目目录下，并使用相对路径如 `video/1-1.mp4`。由于浏览器安全限制，直接打开本地视频可能需要将项目部署到本地服务器（如用 VS Code 的 Live Server 插件）。

2. **PDF处理**: 当前版本讲义以纯文本形式导入。如需阅读原始PDF，建议先用工具将PDF内容提取为文本后导入。

3. **浏览器兼容性**: 推荐使用 Chrome、Edge、Firefox 等现代浏览器。语音朗读功能需要浏览器支持 Web Speech API。

4. **AI提炼**: 我（AI助手）可以帮你将视频讲义、重点背记手册等PDF内容整理成上述JSON格式。你可以：
   - 将PDF中的文字内容复制给我
   - 我帮你按规范格式整理成可直接导入的JSON
   - 将整理好的JSON粘贴到系统的导入区域即可
